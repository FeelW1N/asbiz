# Домашнее задание 2

Модель извлекает признаки обращения, а решение о передаче человеку принимает
код по регламенту. Проверки цитаты и номеров платежей сохранены.
Все 107 тестов проходят.

## Что изменено после первого замера

В исходной версии были краткие описания признаков и два примера. После
проверки на `dev` уточнены правила:

- Новый возврат отличается от вопроса о его статусе, спора с продавцом и
  ошибочного перевода по СБП. Добавлены три собственных примера этих различий.
- Комиссии и вывод выручки относятся к «тарифам», способы оплаты — к «платежам».
- Обычная просьба о возврате имеет срочность 2, полный отказ приёма платежей
  через API — 5.

Изменения проверялись вместе, поэтому вклад каждого примера отдельно не измерялся.
Примеры не взяты из датасета. Модель — `deepseek-flash`, температура — 0.
Постановка дорабатывалась только на `dev`; `test` использован для итогового замера.
